How every class works

Each session follows the same four steps, so kids always know what comes next.

  1. Imagine and innovate

    Pick a challenge or study a set one, then sketch a plan. What should the robot do?

  2. Build

    Snap, screw or code the parts together with a mentor nearby.

  3. Compete and test

    Switch it on. Compete against other builders and see what works and what doesn't.

  4. Improve

    Fix one thing, try again, and show the group.

For parents

Small groups

Few kids per mentor, so every child gets help when they're stuck.

Safe kits

Low-voltage parts only. Younger tracks use no soldering or sharp tools.

No experience needed

We start from zero. Curiosity is the only requirement.
